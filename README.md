# Schaltli Community

Hier geht es um Schaltli: Fragen stellen, Ideen einbringen, Projekte zeigen.

Schaltli besteht aus dem Designer im Browser, der Firmware für die Displays
und der Android-App. Das Handbuch steht auf [schaltli.com](https://schaltli.com),
eine Demo des Designers auf [demo.schaltli.com](https://demo.schaltli.com).

**Mitreden:** in den [Discussions](https://github.com/schaltli/community/discussions).
Du brauchst dafür ein GitHub-Konto.

**Fehler melden** kannst du dort auch. Ist der Fehler klar, wird daraus ein
Issue im passenden Repo:
[Designer](https://github.com/schaltli/schaltli-designer),
[Firmware](https://github.com/schaltli/schaltli-firmware),
[Android](https://github.com/schaltli/schaltli-android).
